# ROSMaster-X3 Autonomous Mobile Robot – for Warehouse & Indoor Automation

## 🛠️ Problem Being Solved
Many mobile robots lack well-tested indoor navigation stacks, limiting their safe use in warehouses and research environments.

## ✅ Solution Overview
Deployed a complete ROS 2-based navigation system on a mobile robot for real-time SLAM, multi-point planning, and obstacle avoidance.

## 🧠 Technical Details
- **SLAM:** RTAB-Map with stereo camera and LIDAR
- **Navigation:** Nav2 stack with dynamic planning
- **Sensor Fusion:** LIDAR + IMU + wheel odometry
- **Visualization:** RViz2 with real-time feedback
- **Hardware:** Jetson Orin Nano, ROS 2 Foxy

## 📊 Key Results
- Accurate 2D/3D mapping
- Stable indoor autonomous navigation
- Real-time replanning with moving obstacles
- Seamless hardware-sensor-software integration
